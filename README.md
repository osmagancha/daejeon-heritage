# 한밭기행 — 대전 문화유산 인터랙티브 투어

대전의 문화유산 13곳을 지도·이야기·3D 모형으로 걷는 웹 앱입니다.
스탬프를 모으고, 퀴즈를 풀고, 포인트로 굿즈를 교환할 수 있습니다.

## 실행

```bash
node server/index.js
```

브라우저에서 <http://localhost:4173> 을 엽니다.
**의존성 설치가 필요 없습니다.** Node 18 이상만 있으면 됩니다 (`npm install` 불필요).

포트를 바꾸려면 `PORT=3000 node server/index.js`.

## 화면 구성

| 화면 | 설명 |
|---|---|
| **지도** | 문화유산 13곳의 마커, 테마 코스 경로(점선), 내 위치. 마커를 누르면 상세 시트가 열립니다. |
| **상세 시트** | `이야기` · `3D 체험` · `연표·정보` · `퀴즈` · `방문` 5개 탭 |
| **테마 코스** | 4개 코스. 선택하면 지도에 순서 번호와 경로가 그려집니다. |
| **문화유산 둘러보기** | 검색 + 분류 필터 + 목록 |
| **내 스탬프** | 스탬프 보드, 배지 8종, 완주율, 방문 기록 |
| **탐방 랭킹** | 포인트 순위 |
| **대전 소개** | 삼국시대~현대까지 시대별 도시사, 5개 자치구 |
| **대전 특징** | 먹거리 · 특산품 · 명소 · 축제 |
| **굿즈 상점** | 포인트 교환 + 외부 상점 링크 |

## 구글 로그인 (직접 실행할 때만)

기본은 이메일 + 비밀번호입니다. 구글 로그인을 켜려면 클라이언트 ID 가 필요합니다.

1. <https://console.cloud.google.com> 에서 프로젝트 생성
2. **API 및 서비스 → OAuth 동의 화면** → 앱 이름 지정, 사용자 유형 '외부'
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
4. 애플리케이션 유형 **웹 애플리케이션**
5. **승인된 JavaScript 원본** 에 `http://localhost:4173` 추가
6. 발급된 클라이언트 ID 를 넣습니다

```bash
cp server/config.json.example server/config.json
```

`config.json` 의 `googleClientId` 에 붙여 넣고 서버를 다시 시작하면 로그인 창에
'구글로 계속하기' 버튼이 나타납니다. 환경변수 `GOOGLE_CLIENT_ID` 로 줘도 됩니다.

서버는 브라우저가 받아 온 ID 토큰을 구글 공개키(JWKS)로 **직접 검증**합니다
(`server/google.js`, 외부 라이브러리 없음). 발급자·대상·만료·서명을 모두 확인하며,
같은 이메일로 이미 가입한 계정이 있으면 그 계정에 구글을 연결합니다.
클라이언트 ID 가 없으면 버튼은 아예 나타나지 않고 이메일 로그인만 동작합니다.

> 배포판(단일 HTML)에는 구글 로그인이 없습니다. 토큰을 검증할 서버가 없고,
> 아티팩트 보안 정책이 구글 스크립트 로드를 막기 때문입니다. 배포판은 이름만
> 입력하면 바로 시작합니다.

## 실제 서버로 운영하기 (Vercel + Neon, 둘 다 무료)

카드 등록 없이 무료로 쓸 수 있는 조합입니다.

### 1. 데이터베이스 (Neon)

<https://neon.com> 에 GitHub 계정으로 가입하고 프로젝트를 만든 뒤
**Connection string** (`postgresql://...`) 을 복사해 둡니다.

서버리스에는 파일을 저장할 곳이 없으므로 이 단계는 **필수**입니다.

### 2. 배포 (Vercel)

1. <https://vercel.com> 에 GitHub 계정으로 가입
2. **Add New → Project** → 이 저장소 선택 → Import
3. Framework Preset 은 **Other**, 나머지 설정은 그대로 둡니다
4. **Environment Variables** 에 두 개를 넣습니다

   | 이름 | 값 |
   |---|---|
   | `DATABASE_URL` | Neon 접속 문자열 |
   | `GOOGLE_CLIENT_ID` | 구글 OAuth 클라이언트 ID (안 쓰면 생략) |

5. **Deploy**

`public/` 은 정적 파일로 그대로 나가고, `/api/*` 요청만
`api/[[...path]].js` 함수가 받아 `server/api.js` 로 넘깁니다.

### 3. 구글 로그인 주소 등록

구글 클라우드 콘솔 → 해당 OAuth 클라이언트 → **승인된 JavaScript 원본** 에
배포된 주소(`https://....vercel.app`)를 추가합니다. localhost 항목은 그대로 둡니다.

### 동시 접속과 데이터 안전

서버리스는 인스턴스가 여러 개 뜰 수 있어, 두 사람이 같은 순간에 기록을 남기면
한쪽이 덮어써질 수 있습니다. `server/db.js` 는 쓰기 요청마다 PostgreSQL 의
자문 잠금(advisory lock)을 잡고 최신 상태를 읽어 처리하므로 그런 일이 없습니다.
읽기 요청은 잠그지 않습니다.

전체 상태를 한 행(JSONB)에 담는 단순한 구조라 학급·학교 규모에는 충분하지만,
수천 명 규모가 되면 표를 나눠야 합니다.

### 내 PC 에서 개발할 때

`DATABASE_URL` 이 없으면 자동으로 `data/store.json` 파일에 저장하므로
아무 설정 없이 `npm start` 만 하면 됩니다. Neon 을 붙여서 쓰고 싶으면
프로젝트 폴더에 `.env` 파일을 만들고 `DATABASE_URL=...` 한 줄을 적으세요
(`.env` 는 git 에 올라가지 않습니다). 파일에 데이터가 있는 상태에서 DB 를
처음 붙이면 기존 내용을 한 번 옮겨 줍니다.

### Render 를 쓰고 싶다면

`render.yaml` 이 들어 있어 **New → Blueprint** 로 배포할 수 있습니다.
다만 2026년 기준 무료 인스턴스에도 카드 등록을 요구합니다.

## 아바타 키우기

메뉴 › **내 아바타**. 탐방할수록 자라는 3D 분신입니다. 서른 단계.

| 기수 | 단계 | 모습 |
|---|---|---|
| 배움 | 1~5 | 댕기머리 아이 |
| 유생 | 6~10 | 유건 |
| 선비 | 11~15 | 갓 |
| 유림 | 16~18 | 갓과 흰 수염 |
| 관료 | 19~20 | 사모와 흉배 |
| **영물** | 21~25 | 도깨비 · 야차 · 해태 · 삼족오 · 구미호 |
| **신격** | 26~28 | 청룡 · 산신령 · 염라대왕 |
| **초월** | 29~30 | 돌부처 · 천지신명 |

스무 단계까지는 사람으로 자라고, 그 위로는 옛이야기 속 영물과 신격으로 넘어갑니다.

### 성장 속도

필요 포인트는 (단계-1)^2.4 곡선을 따르며 마지막 단계는 130,000P 입니다.
탐방·퀴즈·후기로 얻는 점수는 한 번씩만 들어오므로 장기 수입원은 매일 문안입니다.
연속 7일부터 하루 70P 가 상한이니, 하루도 거르지 않아도 **약 5년**이 걸립니다.

### 3D 아바타

모델 파일 없이 three.js 기본 도형으로 짓습니다(`public/js/avatar-3d.js`).
드래그로 돌리고 휠·두 손가락으로 확대할 수 있습니다.
`server/avatar.js` 의 `form` 명세가 생김새를 정하며, 서버와 배포판이 같은 파일을 씁니다.

- **꾸미기** — 도포 8색, 지물 8종. 스탬프·퀴즈·후기·배지·연속 문안·단계로 열립니다.
  조건을 만족하지 않은 항목은 서버가 장착을 거부합니다.
- **오늘의 문안** — 하루 한 번(한국시간), 연속으로 할수록 늘어 최대 70P.

칭호와 생김새는 조선의 학제와 우리 옛이야기에서 이름만 빌린 놀이용 설정입니다.

## 관리자 페이지

메뉴 맨 아래 **관리자** 항목은 관리자로 지정된 계정에게만 보입니다.

### 관리자 지정

`ADMIN_EMAILS` 환경변수에 이메일을 쉼표로 나열합니다.

```
ADMIN_EMAILS=teacher@school.kr,me@example.com
```

Vercel 은 대시보드 Settings 에서, 내 PC 는 `server/config.json` 의
`adminEmails` 배열에 적습니다. 서버를 다시 띄워야 반영됩니다.

**화면이나 DB 로는 관리자를 만들 수 없습니다.** 그렇게 두면 DB 를 고칠 수
있는 경로가 곧 관리자가 되는 길이 되기 때문에, 배포 설정에서만 읽습니다.

### 할 수 있는 일

| 탭 | 내용 |
|---|---|
| 현황 | 가입자·스탬프·후기·퀴즈 집계, 최근 2주 추이, 최근 활동 25건 |
| 사용자 | 검색, 포인트 수정, 계정 삭제(딸린 기록까지 함께) |
| 후기 | 전체 후기 목록과 삭제 |
| 문화유산 | 유산별 방문자·현장인증·평점·퀴즈 정답률 |

자기 계정과 다른 관리자 계정은 삭제할 수 없습니다.
계정을 지우면 스탬프·후기·퀴즈·배지·주문 기록이 함께 지워지며 되돌릴 수 없습니다.

## 공유용 배포판 만들기

서버 없이 도는 단일 HTML 파일을 만듭니다.

```bash
python tools/make-basemap.py      # 지도 데이터 굽기 (처음 한 번)
node tools/build-standalone.js    # dist/hanbat.html 생성
```

지도는 타일 이미지를 내려받지 않고 OSM 데이터(ODbL)로 경계·하천·도로·철도를
받아 앱이 직접 벡터로 그립니다. 배포판에서는 로그인 대신 이름만 입력하며,
기록은 방문자의 브라우저에 각각 저장됩니다.

## 주요 기능

- **3D 체험** — 외부 모델 파일 없이 three.js로 각 건축물을 **코드로 짓습니다**.
  팔작지붕은 링을 쌓아 올리는 로프팅으로 처마의 들림과 지붕선의 오목함을 재현했고,
  석축·창호·기와는 캔버스로 생성한 절차적 텍스처를 씁니다.
  노란 점(주석)을 통해 굴뚝·치(雉)·봉수대·코니스 같은 부위 이름을 확인할 수 있습니다.
- **일러스트레이션** — 사진 없이, 각 유산의 형식과 팔레트로 SVG 장면을 생성합니다.
  같은 유산은 항상 같은 그림이 나오도록 id 기반 시드를 씁니다.
- **오디오 가이드** — Web Speech API로 현장 해설을 한국어로 읽어 줍니다.
- **스탬프 인증** — 현장 800m 이내면 GPS 인증(정포인트), 그 밖은 직접 체크인(40%).
- **배지** — 첫 걸음 / 탐험가 / 대전 마스터 / 선비 / 분류별 3종 / 코스 완주.
- **라이트·다크 테마** — 지도 타일에도 필터가 적용됩니다.
- **반응형** — 화면 크기에 따라 구조가 다릅니다.
  - 모바일: 지도 위 바텀시트 + 아래쪽 가로 스크롤 띠
  - 860px 이상: 왼쪽에 문화유산 세로 목록 패널, 오른쪽에 상세 패널, 가운데 지도

## 구조

```
server/
  index.js          의존성 없는 HTTP 서버(정적 파일 + API + 레이트 리밋)
  api.js            라우트 핸들러 전부
  auth.js           scrypt 비밀번호 해시, 세션 토큰
  db.js             JSON 파일 저장소(원자적 쓰기, 40ms 배치)
  seed/heritage.js  문화유산 13곳 · 테마 코스 4개 · 배지 8종
  seed/city.js      굿즈 · 대전 소개 · 대전 특징 · 공지
data/store.json     런타임 데이터 (자동 생성)
public/
  index.html
  css/style.css     디자인 시스템(단청 팔레트, 한지 질감, 유리 표면)
  js/api.js         API 클라이언트 + 전역 상태
  js/illustrate.js  절차적 SVG 일러스트
  js/three-view.js  절차적 3D 뷰어
  js/map.js         Leaflet 지도
  js/panels.js      시트·뷰·드로어·모달 렌더링
  js/app.js         이벤트 연결
```

## API

인증은 `Authorization: Bearer <token>` 헤더로 합니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/bootstrap` | 유산 목록·코스·배지·공지·평점 한 번에 |
| GET | `/api/heritage/:id` | 상세 + 후기 + 평점 + 주변 유산 |
| POST | `/api/auth/register` \| `/login` \| `/logout` | 계정 |
| GET/PATCH | `/api/auth/me` | 내 요약(방문·배지·퀴즈·코스 진행) / 프로필 수정 |
| POST/DELETE | `/api/visits` , `/api/visits/:heritageId` | 스탬프 |
| POST | `/api/favorites/:heritageId` | 즐겨찾기 토글 |
| POST/DELETE | `/api/reviews` , `/api/reviews/:id` | 후기 |
| POST | `/api/quiz` | 퀴즈 채점 + 포인트 |
| POST | `/api/orders` | 굿즈 포인트 교환 |
| GET | `/api/goods` `/api/city/intro` `/api/city/features` `/api/leaderboard` | 조회 |

## 포인트

| 행동 | 포인트 |
|---|---|
| 가입 | +100 |
| 현장 GPS 인증 | 유산별 100~200 |
| 직접 체크인 | 위 금액의 40% |
| 퀴즈 정답(문항당 1회) | +30 |
| 후기 작성(유산당 1회) | +20 |

모두 모으면 약 2,800P. 굿즈는 400~1,950P입니다.

## 데이터 출처

국가유산청·대전광역시 공개 자료를 바탕으로 재구성한 교육용 콘텐츠입니다.
3D 모형은 실측 도면이 아니라 건축 형식·비례·구조를 이해하기 위한 **해석 모형**입니다.

## 외부 리소스

CDN에서 Leaflet 1.9.4, three.js r128, Google Fonts(Gowun Batang, Noto Sans KR)를,
지도 타일은 OpenStreetMap을 사용합니다. 인터넷 연결이 필요합니다.
